# Three-minute demo

1. **Pain (20s):** show the synthetic raw alert count and explain the many-tools/many-pages problem.
2. **Console (40s):** open SignalDesk and show the situation list ranked P1–P4. Point out the permanent redaction badge and synthetic replay label.
3. **Evidence (40s):** select a multi-service situation, show the probable-origin hint, timestamps, alert count, and reasons. State that the prototype uses a deterministic template/time baseline.
4. **Tuning (35s):** open the backlog, distinguish protected predictive signatures from low-evidence review rows, and inspect the what-if figures.
5. **Approval safety (25s):** approve a reviewable row with a name and reason. Show the `NOT APPLIED — export only` confirmation and local export/audit record.
6. **Metrics and honesty (30s):** show synthetic held-out metrics and call out unavailable B-Cubed/ARI/time-to-surface measurements. Finish with the historical-bias limitations.

## 60-second fallback

Show a situation and its explanation, then the protected alert in the tuning backlog and the safety page. Remind the audience that the demo uses generated data and has no live monitoring write path.
